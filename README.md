# Excel Formulas Practice

## About This Repository
This repository contains my practice work and examples using Microsoft Excel formulas and functions. The goal is to improve my spreadsheet skills, data analysis, logical thinking, and ability to solve practical problems using Excel.

## Objectives
- Learn and practise essential Excel formulas.
- Understand mathematical, logical, and statistical functions.
- Perform calculations and analyse datasets.
- Improve data handling and problem-solving skills.
- Build a portfolio of practical Excel exercises.

## Topics Covered

### 1. Basic Formulas
- Addition, subtraction, multiplication, and division
- SUM()
- AVERAGE()
- MIN()
- MAX()
- COUNT()
- COUNTA()


### 2. Conditional Formulas
- SUMIF()
- SUMIFS()
- COUNTIF()
- COUNTIFS()
- AVERAGEIF()
- AVERAGEIFS()


### 3. Lookup Functions
- VLOOKUP()
- HLOOKUP()
- XLOOKUP()
- INDEX()
- MATCH()

## Tools Used
- Microsoft Excel
- Sample datasets for practice
